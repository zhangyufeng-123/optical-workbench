# 光纤与空间光路设计台 · 使用说明

## V5.9 文字编辑与字体

论文渲染完成后，直接点击图中文字，右侧可修改内容、中英文字体、字号、粗体、颜色和引线。拖动文字调整位置，方向键可微调，Shift 加方向键可加大移动步长。文字编辑区提供撤销、重做、添加和删除。

“将字体样式应用到全部文字”使用当前标注的字体、字号、粗体和颜色统一整图。顶部“字体”入口可统一设置中英文字体，应用后立即更新当前图。提供 25 种中文和 29 种英文字体，列表标出本机未检测到的字体。

文字内容、字体和位置随三维工程保存，重新渲染时按对应器件恢复。下载 PNG、SVG 和完整包包含最新修改。需要多幅图组合时使用“多图排版”，在其中继续修改的文字会同步回渲染结果。

## V5.8 一键排版

点击顶部“一键排版”，软件按已有连接安排主链和分支，并依据器件尺寸整理间距及光纤走线。组合器件和相连空间光段整体移动，锁定器件作为固定位置参与布局。整次排版支持一次撤销和重做。

在“布局 → 输入连接关系”中填写例如“光源 → 起偏器 → 偏振控制器 → 绕制光纤 → 偏振分析仪”，点击“生成并排版”。已有器件会复用，缺少的器件自动从器件库添加。分支按多行书写，可用“分光器.a → 探测1.in”指定端口。同类器件先声明别名，例如“探测1 = photodiode”。窗口提供完整示例及当前器件端口表。

默认使用当前台面尺寸，空间不足时可在连接关系窗口勾选“空间不足时自动扩展台面”。手动走线点在刚性组合内部随组合平移，跨组连线按新位置重新布线。再次执行会复用现有关系，端口冲突或名称歧义会显示具体提示。

双击 **打开光纤实验搭建台.html**，使用新版 Chrome 或 Edge。请将整套文件保留在同一文件夹。日常搭建、编辑、保存和出图可离线运行，无需安装 Blender、Node.js 或启动服务器。

## V5.4.1 光路原色输出

一键论文渲染默认勾选“保留光路原色”，按工程设置的颜色输出光纤护套、连接头尾套和光束核心。透明 PNG、SVG 内嵌画面及快速 PNG 同步保持光路原色。光束光晕采用同色透明叠加。可在渲染设置中取消该选项，继续使用材质受光的效果。

## V5.4 搭建操作

- 连接光路时点击“取消连接”或按 Esc，退出本次连接。选中连接后可在属性栏点击“删除此连接”，连接列表也可删除，支持撤销。
- 器件库支持部分名称、多关键词、常见中英文同义词和英文单字符拼写偏差的模糊搜索。Ctrl+K 的器件搜索同步。
- “视图 → 扩展实验台 25%”一键放大台面。在“设置”输入宽和深可精确调整，最大为 10000 × 10000 mm。
- Shift 多选器件，在“工具 → 组合器件与立杆”中组合、拆开、保存或添加组合文件。组合整体选择、移动、旋转和复制，内部连接与手动走线随组合变换。
- 选中器件后，属性栏直接设置高度 Y，或点击升高、降低 10 mm。“添加立杆 / 组合”可设置立杆高度、杆径与底座尺寸。添加或调整立杆时，器件与光学端口同步升降。Y 为器件坐标原点的高度，整体移动会一起移动立杆。

## 透视渲染

一键论文渲染采用 40° 视场角的透视相机，近处器件更大、远处器件更小。自动构图按器件、连线与所选桌面的空间深度计算取景距离。当前视角、自动构图、立体视角、低角度与俯视均采用透视投影。渲染完整包的参数文件记录投影类型与视场角。

## 带连接端口的 GLB

导入带有 opticalPorts 元数据的 GLB 后，平台自动建立光学连接点。随包提供的 AQ6373E 修订模型采用前面板右下角 FC/PC 输入端口，点击该端口即可连接光纤。该模型保留米制尺寸标记，导入时转换为毫米。普通 GLB 继续按最长边 160 mm 导入，可在属性中调整尺寸和端口。

## 文字显示与隐藏

**字体选择**：在“工具 → 字体与字号”选择 25 种中文和 29 种英文字体，分别设置画布字号、论文字号与加粗。默认中文宋体、英文 Times New Roman；预览始终可见，应用字体不会自动打开隐藏名称。论文渲染窗口也可通过“字体”入口修改；论文排图支持全局字体和单条文字独立字体，导出 PNG / SVG 同步。

字体使用本机已安装资源，换电脑未安装时会回退；工程保存字体选择，不打包系统字体。可查看 `预览/V5.3_字体搭配示例.png` 的本机实际字体样张和同名可编辑 SVG。

默认隐藏器件名称与通用模型上的机身文字。在“视图 → 显示”中可分别开启“器件名称”“机身文字”，选择随工程保存并支持撤销；快速 PNG 和新论文快照同步。论文渲染窗口的“自动标注”可单独开启。已有论文面板与手工标注保留，自有导入模型的纹理保留。

## V5 工作区：简洁界面与精确绘图

**V5.1 新增展示构图**：在“视图 → 展示构图”推荐角度、整组居中和保存三视角。直接使用摆好的示例：文件 → 场景模板与台面 → 推荐展示 · 45°主视角。查看 `展示角度对照.html` 比较实际 Blender 画面；操作详情见 `V5.1展示构图说明.md`。

本次按“减少文字密度、整理工具入口、补齐精确绘图和场景管理”的方案完成升级。详细方案见 `source/design_workbench_v5.md`。

顶部只保留文件、撤销/重做、搜索、配色和论文渲染。**文件** 中可保存/打开工程、导出图片、三维模型和器件清单；**布局** 中有对齐、等距和布局检查；**工具** 中有精确变换、对象管理、绘图工具。**视图 → 专注画布** 收起侧栏，画布右上方的 **退出专注** 恢复；切白底后仍可点 **恢复实验台**。

左侧默认用紧凑器件列表，类别改为下拉，可切换图卡。右侧分成 **属性 / 对象 / 设置**；模板、台面、保存视角和界面密度在“设置”中。主界面采用统一无衬线字体与字号；论文图内的宋体和 Times New Roman 保持原设置。界面密度与列表偏好仅保存在当前浏览器。

**工具 → 材质与光照** 提供技术示意、精致材质和展示质感三个预设，可调玻璃通透、金属粗糙度、光束柔光和曝光；随工程保存并支持撤销。透明玻璃采用透射材质，仪器外壳与金属镜架使用不同表面高光，光束用细亮核心和渐弱光晕表示。自有模型保留其原材质。论文渲染窗口也可进入材质设置；改完后重新渲染。灰色参考图可用“灰色实验台 + 简洁台面”，需要孔阵列时继续选择“完整实验桌”。

参考配色可载入 `示例工程/V5精致材质_参考光路.json`。Blender 中新增器件请优先使用 `模型/V5_光学器件库_100类_精致材质.blend`，100 个器件集合和打包纹理均保留；两个 `V5_精致材质_*.blend` 提供完整实验桌与简洁灰色台面的灯光、材质和后期节点示例。旧 GLB 是历史导出快照，需要当前材质时请从平台重新导出。

按 **Ctrl+K** 搜索工具或器件，例如“PBS”“凸透镜”“阵列”“恢复实验台”；↑/↓ 选择、Enter 执行、Esc 返回。不可用的操作会提示需要什么选择。器件搜索在输入查询后出现，执行“添加…”即可加入台面。

**工具 → 精确变换**：先选一组器件，再输入相对 X/Y/Z 位移和绕组中心的角度；切换“阵列复制”可生成 1–20 份额外副本。副本保留组内连接、端口与颜色，重新分配标识；外部连接不复制。旋转中心是未锁定选件中心位置的平均值，内部手动光纤控制点一起变换。跨组手动控制点仍在原世界坐标，工具会提醒复核；锁定器件跳过。正角度按 Three.js 的 +Y 轴旋转。整个操作一次撤销。

**工具 → 对象管理**：搜索名称/类别/短标签，筛选可见、隐藏或锁定对象，批量显示、隐藏或锁定；“选择连通链路”按已存连接选择整个连通部分，包含分束支路，默认不穿过隐藏对象。可保存最多 20 个常用选择集，随工程 JSON 保存。选择集只记成员，不是刚性机械组；删除后的成员会被过滤，空集合不会变成全选。

**示例工程/V5精确绘图/** 提供“全光纤双通道_阵列与选择集.json”和“空间分束_支路选择集.json”。打开工程会替换当前场景，先保存自己的工程。两份是绘图功能示例，不是新增实验结果。

V5 验证范围和新版文件清单见 `V5优化说明.md`。此前版本的浏览器/Blender 预览记录不作为本次新界面视觉验收。

## 配色与绘图增强版

上方 **一键配色** 可使用论文蓝橙、石墨红光、海蓝铜金、矿物绿紫、色觉友好、暗场荧光六套色板。器件外壳、激光、光纤、背景和实验桌可以一起协调，也可以只改选中部分。选择色板后点击 **应用配色**；界面会列出预计修改的器件和连接数量。自有 GLB 保留原材质，锁定项默认跳过，颜色属于示意编码，不代表实际波长或功率。

可调整单个颜色、切换按路径或单色显示、批量设定光束直径和光晕、导入导出配色 JSON。色板保存进工程；渲染窗口勾选 **沿用工程配色** 即可保持背景与桌面颜色。直接点击渲染风格会使用该风格的背景，并自动重新生成已有图；不会继续显示没有更新的白底结果。

**绘图工具** 提供复制样式、粘贴样式、锁定颜色、短标签编号和子装配保存/追加。选择一组器件，保存为子装配 JSON 后，可以在其他工程追加使用，内部连线跟随并重新分配标识；当前场景不会被覆盖。样式快捷键为 Ctrl+Shift+C / Ctrl+Shift+V，输入文字时不触发。

任何时候切到白底后，都可点击 **恢复实验台**，恢复灰背景和孔阵列桌面。这个操作保留器件、光束的颜色、连线、坐标和当前观察角度，也支持撤销。主页面和渲染窗口均有此按钮。

**示例工程/一键配色/** 包含六套完整工程 JSON、六份独立配色 JSON，以及带内部连接的 PBS 分支子装配。完整工程用“打开工程”载入；配色文件在“一键配色 → 导入配色”载入；子装配在“绘图工具 → 导入并追加子装配”载入。三种文件用途不同，不能互换。载入完整工程前先保存自己的当前工程。

**预览/配色_论文蓝橙_Blender.png** 与 **预览/配色_暗场荧光_Blender.png** 是实际三维模型的 Blender 配色审阅图，配套 `.blend` 位于 **模型/**，可继续编辑。它们不是浏览器出图截图；浏览器和 Blender 的光照、色调映射不同，最终图片应在实际输出尺寸下复核。

本次工作流参考 GitHub 上 Excalidraw 的主题与可编辑保存、Penpot 的设计色板与组件复用、draw.io 的绘图编辑方式。研究链接与取舍见 `source/design_palette_upgrade.md`；未复制这些项目的代码。新增配色、恢复背景、导出状态与子装配已经过程序检查，Blender 预览已实际渲染检查；本次新增网页交互未在受限的内嵌浏览器中实测，详见 `一键配色增强说明.md`。

## 一键生成论文光路

### 实验桌显示

默认保留原来的孔阵列实验桌。搭建画面右下角的 **实验桌** 勾选框可显示或隐藏桌面，并随工程 JSON 保存；快速 PNG 与论文排图快照跟随这个勾选框。**实验搭建** 按钮恢复桌面，**白底刊图** 按钮隐藏桌面以便预览纯白图。

一键渲染窗口提供独立的 **实验桌** 选项：**完整实验桌（孔阵列）／简洁台面／不显示桌面**，默认不显示桌面。四种风格均可自由搭配，白底也能带桌面。透明背景仅控制桌面外的背景是否透明；桌面是否显示由实验桌选项决定。已有页面须先保存工程，再按 Ctrl+F5 更新；已有 PNG 不会自动改变，需要重新渲染。

搭好链路后，点击画布上方的 **一键论文渲染**。无需先填参数，默认论文白底、自动构图、183 mm 双栏幅宽、600 dpi，并按字体实际宽度避让标签。手动选择过风格后继续保留该选择。输出使用当前可编辑三维模型与连接，渲染结束后恢复编辑器的器件材质、光照、视角和可见状态。

| 渲染风格 | 画面效果 | 适合用途 |
| --- | --- | --- |
| 论文白底 | 白色背景与柔和投影 | 光纤链路、论文主图 |
| 灰色实验台 | 灰色实体台面、灰色背景和独立光照 | 空间光路、红色激光示意 |
| 深色光路 | 深色实体台面与冷调轮廓光 | 突出光束路径与分支 |
| 暖灰演示 | 浅暖灰台面和柔和光照 | 报告与实验装置展示 |

完整实验桌和简洁台面都参与三维渲染并接收阴影。背景选 **不透明 · 随风格** 时输出风格底色，选 **透明背景** 时桌面外透明。选择不显示桌面时仅保留器件、连接与柔和投影。

结果窗口提供 **下载 PNG**、**可编辑 SVG**、**下载全部**、**多图排版**。直接点击预览文字即可编辑内容、字体和位置。下载全部一次保存六个文件：高清 PNG、SVG、论文排版 JSON、三维工程 JSON、渲染参数 JSON 和编辑说明。多图排版可组合面板、调整引线或添加箭头，修改会同步回当前渲染结果；完整排版请保存论文排版 JSON。

结果上方可以切换上述四种风格、透明背景、当前视角、俯视、89 mm 单栏或 300 dpi，然后点击重新渲染。首次点击会进行多次光照与边缘采样，速度取决于电脑和场景复杂度。密集长标签会自动换行并分配至画面空白处；几何本身重叠时，应返回搭建台调整器件间距。中文标签使用宋体，外文使用 Times New Roman。

浏览器里已打开旧页面时，先点 **保存工程** 备份当前搭建，再按 **Ctrl+F5** 载入新版。

## 先完成一张论文光路图

1. 在“实验搭建”中从左侧添加器件，或用“打开工程”载入示例。库中可搜索、按类别筛选、收藏常用器件；同类器件可以重复添加。
2. 左键拖动器件；空白处拖动旋转视角，右键平移，滚轮缩放。右侧填写位置、转角、缩放和备注。用俯视排好器件，再调整立体视角。
3. 点“连接光路”，选择“自动识别端口”并依次点两个端口；也可点右侧端口按钮。光纤连接可调整松弛量与手动控制点，空间光连接是端口之间的直线光束。连接方式见下文。
4. 切换“白底刊图”检查器件间距、线缆遮挡和标签。给器件设置简短论文标签，如 Source、LP、FPC、DUT、PSA；中文名称及实验参数可保留在名称或备注中。
5. 打开“论文排图”，添加当前光路快照；可继续添加视角或导入 Origin 导出的 PNG / 自包含 SVG。选择幅宽、分辨率和布局，再用文本、箭头、引线调整标注。
6. 分别保存“工程 JSON”和“论文排版 JSON”，最后导出 PNG 或 SVG。两种 JSON 保存不同内容，均应备份。菜单中的快速 PNG 用于预览；需要指定毫米幅宽和 DPI 时，使用论文排图导出。

## 器件库与模型文件

- **100 类三维器件**：保留原 60 类光纤与实验台器件，并增加 40 类空间光器件。原库包含光源、偏振与样品、无源器件、有源器件、测量、光纤传感、连接与机械七类；新增空间光源、空间光学、空间调制、空间探测四类。包括激光源、准直器、光纤准直器、反射镜、透镜、物镜、分束器、PBS、波片、光阑、滤片、光栅、棱镜、扩束器、延迟线、吸收器、离轴抛物面镜、二向色镜、AOM、EOM、SLM、DMD、快门、相机、单光子与平衡探测等。具体名称和端口以左侧库为准。
- **489 个二维 SVG 符号**：另行打开 `光纤符号库.html` 搜索、分类、下载。源自 GitHub Photonics Component Library；它们是二维功能符号，不是可直接拖入三维台面的模型。
- **模型/**：包含 100 个独立器件 GLB、三种空间光示例场景，以及 `光学器件库_100类独立集合.blend` 和 `100类器件陈列台.glb`。100 类 Blender 库已实际重开验证，包含 100 个可追加的 Asset Collections，纹理已打包。Blender 中使用 File → Append → Collection 或 Asset Browser 追加器件；移动集合内的 `MOVE_THIS` 父对象可整体摆放，再分别编辑网格和材质。此前的 `全光纤测试台_增强版.blend`、`光纤器件库_60类独立集合.blend` 也予以保留，其中“60 类”是历史快照。
- **示例工程/**：提供可继续修改的搭建工程。**source/** 保存参数化模型、编辑器与出图模块源码；**vendor/** 保存依赖和许可证。

三维模型是本项目参数化制作的通用可视化外形，非厂商精确 CAD、制造图或真实照片。新增模型不来自 OEM 模型库。来源见 `来源与许可.md`、`source/component_sources.md` 与 `source/free_space_components.md`。可以修改、重复添加或替换当前库件；这里的“100 类”是本版覆盖数量，不表示包含所有市售器件。

| --- | --- | --- |
| 空间激光 · 折叠光路 | `laser_bench` | 直线激光段经器件串接形成折叠路径 |

## 选择、对齐与编辑

Shift + 点击器件或右侧列表可增减选择；右侧列表也支持 Ctrl + 点击。“全选”选择可见器件。“对齐 X / Z”按器件中心对齐；等距分布至少需要三个未锁定器件。多选复制会同时复制这些器件之间的内部连线，并分配新 ID，不会连回原器件。

拖动吸附开启时，主拖动器件按 25 mm 绝对网格定位，其余所选器件随相同位移移动，保持相对距离。右侧可精确输入 X、Z、Y 高度、转角、整体缩放、外壳色、备注和短论文标签。导入 GLB 保留原材质，复杂材质修改请在 Blender 中完成。

“锁定”阻止拖动、对齐、键盘移动及删除；操作前先解锁。“隐藏”保留工程对象，但不进入可见图像，其相关连线也隐藏。“图中标签”开关只控制器件标签。左右侧栏可收起以扩大画布。

| 快捷键 | 主搭建工作区功能 |
| --- | --- |
| Ctrl + S | 下载场景工程 JSON |
| Ctrl + Z / Ctrl + Y | 撤销 / 重做 |
| Ctrl + D | 复制所选器件及选件内部连线 |
| Delete | 删除未锁定的所选器件 |
| R | 每个选件各自旋转 15°，不是整组绕共同中心旋转 |
| F | 放大到所选器件 |
| 方向键 / Shift + 方向键 | 移动 25 mm / 1 mm |
| Esc | 取消待连接端口 |

普通输入框获得焦点时，字母、Delete 和方向键用于编辑文字；Ctrl + S 仍可保存。在论文排图窗口中，Ctrl + S 保存排版，Ctrl + Z / Y 操作排版历史，Delete 只删除所选标注，不删除背后的三维器件。

## 光纤连接、空间光束与手动路径

每个端口允许一条外部连线。连接检查覆盖占用、输入/输出方向和接口名称；不校验波段或真实光学性能。连接模式可选“自动识别端口”“激光光束”或 SM / PM / MM 光纤。自动模式依据端口接口决定连接类型：两个 `Free space` 端口形成直线光束，光纤接口形成光纤连接。SM 橙色、PM 蓝色、MM 紫色是辨认路径的默认配色。

空间光只能连接同类 `Free space` 端口，光纤不能直接接到空间光端口。需要跨越两种接口时，从库中添加**光纤准直器**（`fs_fiber_collimator`），分别连接其光纤端和空间光端。选择一条激光光束后，可设置**光束颜色、显示直径 / mm、光晕强度**。颜色和发光效果用于表达路径，显示直径不是计算得到的束腰，光晕不代表散射或功率测量。移动器件时，光束两端随端口更新并保持直线。

每条光纤可设置颜色、松弛量、显示半径、走线侧，以及最多 **20 个手动控制点**。控制点 XYZ 使用世界坐标，单位 mm。移动器件时，连线两端跟随端口，手动控制点仍保持原世界位置；必要时一并修改控制点。点“恢复自动走线”清空控制点。自动走线不自动避让器件，需检查遮挡与交叉。直线光束不使用光纤的松弛量和手动弯曲路径。

通过“编辑端口位置 / 添加端口”设置局部 XYZ、出线方向、接口和输入/输出属性。Y 轴向上。可用“＋空间光端口”添加 `Free space` 端口，也可在端口编辑器中修改接口。修改端口坐标会移动标记和连线端点，不会重建模型的实体接头；更换已连接端口的接口或用途会解除原连线。熔接件使用“尾纤熔接”接口，不作为 FC 插接端口匹配。

“器件清单”导出 CSV，含器件类型、位置、备注、来源和连接端点。“检查布局”提示台面边界、器件外包框重叠及空闲端口；外包框提示不等于真实机械碰撞检测。

## 视角、外部模型与工程备份

可保存最多 **12 个命名视角**，随工程保存。论文快照可选择当前方向、器件立体、低角度或顶视布局。

“导入自有 GLB 模型”接受单文件 `.glb`，每个不超过 **30 MB**。模型最长边先归一为 160 mm；按“真实最长边 / 160”设置整体缩放。默认不添加端口，请按归一化后、整体缩放前的局部坐标自行添加。GLB 的原始品牌、许可和尺寸以来源为准。

“保存工程”生成 `…_工程.json`，格式为 `fiber-workbench`，当前版本 2，可读取版本 1。保存器件、连接、控制点、备注、自定义端口、锁定/隐藏状态、相机、命名视角及导入 GLB。导入模型嵌入 JSON，换电脑不依赖原模型路径。载入上限为 **250 件器件、600 条线、100 MB**；高面数模型仍可能影响显卡性能。收藏保存在当前浏览器中，不随工程迁移。

浏览器暂存仅作为恢复辅助，可能被清理；请主动下载工程。GLB 可导出全场景或所选器件。编辑器布局单位为毫米，GLB 单位为米。GLB / Blender 文件是导出时的几何快照：在三维软件中移器件不会自动重新布线，继续互动搭建请使用工程 JSON。

## 论文排图与 Origin 图

支持 **1–6 幅面板（a–f）**，可上下、并排或两列网格排布。加入三维快照后可添加文本、箭头、直线、矩形、椭圆和引线，拖动标注并在右侧调整属性；支持撤销/重做。三维场景修改不会自动更新已保存的面板，请使用“更新快照”；原标注位置会保留，更新后需检查对齐。

多面板中长中文器件名可能重叠。完整光路宜占一整行；使用短标签、换行、拖动和引线安排标注，再按论文实际尺寸检查可读性。平台提供排版工具，不保证任意标签与面板组合均自动避让。

- **幅宽**：单栏 89 mm、双栏 183 mm，或自定 50–400 mm。高度按面板原始比例与布局自动计算，不拉伸图像。
- **分辨率**：150 dpi 预览、300 或 600 dpi 输出。89 mm / 300 dpi 约为 1051 像素宽；183 mm / 600 dpi 约为 4323 像素宽。PNG 写入对应物理密度信息。
- **背景**：白色或透明。透明背景不会自动去除导入图片已有的白底。
- **字体**：新建标注的中文为宋体（SimSun），外文为 Times New Roman。字体不随包分发；换电脑打开 SVG 时可能发生字体替换，PNG 中字形已栅格化。
- **SVG 的可编辑范围**：文字、箭头、引线、边框和面板编号是独立矢量；三维画面是嵌入位图，并非全矢量三维图。需要修改器件几何请回到工程 JSON 或 Blender。

“导入 Origin 图”接受 Origin 已导出的 PNG 或自包含 SVG；也可载入 JPG / WebP。单图上限 **25 MB**。保留原图内容、比例和来源文件名；原有曲线与字体不在本平台重绘，应在 Origin 中修改后重新导出。本工具不生成实验数据、不运行 Origin 分析。请另行备份 Origin 工程和原始数据，论文排版 JSON 不能替代它们。

SVG 须自包含，不得带脚本、事件、foreignObject、外部或相对资源引用；不满足条件时请从 Origin 重新导出自包含 SVG 或改用 PNG。

论文窗口“保存排版”生成 `…_论文排版.json`，格式为 `fiber-workbench-publication`、版本 1，嵌入面板图像和可编辑标注；“载入排版”上限 **120 MB**。它与场景工程 JSON 不可混用。

## 实验表达的边界

默认外部链路表达光纤光源 → 在线起偏器 → 光纤偏振控制器 → 螺旋光纤波片 → 光纤输入偏振分析仪。实际输入偏振态需标定；PM 慢轴未在通用接头上表示。SLD、EDFA、SOA 等库件的可选存在，不代表均适合 1310 nm 测试。仪器内部是否采用空间光路由具体型号决定。

文献参考波片的 R≈10.45 mm、外绕节距≈42.2 mm、QWP/HWP 弧长约 137/274 mm 是参考几何，不是自制样品的实测参数。光纤内部自旋节距不能与外绕节距混用；自制样品真实参数请记在备注并替换示意结构。

面包板 25 mm 孔距通过纹理表达，未建 M6 实体螺纹。本平台不计算光传播、反射折射、衍射、干涉、束腰、焦点、偏振传播、损耗、波段兼容性、热学、耐压、最小弯曲半径或机械装配公差；连接与布局检查不能替代实验验证及器件规格核对。红色光束是路径示意，并非红外实验的真实可见散射照片。仪器屏幕仅显示功能说明，不代表测量数据。

## 源码重建

日常使用发布页中的 EXE 无需重新打包。开发时编辑仓库内 `app/source/` 中的模块；建议安装 Node.js 24，在仓库根目录运行：

```powershell
npm ci
npm test
npm run build
npm run stage
```

`npm ci` 按锁文件安装开发依赖，`npm run build` 使用仓库声明的 esbuild 构建离线网页，`npm run stage` 整理桌面运行文件。运行 `npm start` 启动开发版，Windows 下运行 `npm run pack` 生成 `dist/` 中的 EXE。构建不依赖原开发者电脑上的工具路径；直接使用已发布 EXE 无需 Node.js。编辑 `.blend` 文件时需另行安装 Blender。软件逻辑检查生成在 `app/qa/`，桌面检查记录生成在根目录 `qa/`；它们不构成物理实验结果。

## V5.6 自定义台面与论文插图

点击画布上方的“台面尺寸”，分别输入宽度和深度，再点击“调整台面”。宽度和深度均支持300–10000 mm，可输入小数，例如1375.5 × 865.25 mm。调整后可通过撤销、重做和工程文件恢复尺寸。

点击右上角“论文渲染”，由软件内置三维渲染器直接生成当前器件与光路的论文插图。默认采用白底、紧凑透视构图、中性光照、柔和阴影及光路原色。实验桌、视角、背景、幅宽、分辨率和标注可以在渲染窗口调整。

需要在图中保留实验桌时，在“实验桌”选项中选择“完整实验桌（孔阵列）”。PNG支持300或600 dpi输出，SVG包含可编辑标注。

### 按文献图例渲染

打开右侧“参考”，搜索或筛选文献，点击卡片上的“按此文献渲染”。软件会加载该图例的背景、观察角度、光照、阴影与哑光参数，直接渲染当前三维光路。渲染窗口显示所选题名、DOI、缩略图和风格类别。

100篇图例采用基于已核验图像和风格分类的参数预设，目前关联14组实际参数。相近图例可以共用一组参数。点击“论文默认风格”可恢复通用预设，选择其他文献可切换表现方式。下载完整包会保存所用文献和渲染参数。

## V5.7 产品器件与光纤连接

图中五器件链路采用Thorlabs DFB13TK、ILP1310PM-FC、FPC031、自制绕制光纤样品，以及带光纤输入组件的PAX1000IR2/M。商用器件外形按公开图纸尺寸和产品照片重建，照片估计细节、尾纤停放位置及可调装配位置保存在产品元数据中。绕制光纤沿用参考几何，绕纤与支撑可以在GLB层级中分别编辑。
